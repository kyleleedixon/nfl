How it's tested

Every number on this page is out of sample. For each season, the model is trained only on earlier seasons, then asked to call every snap of the new one. Nothing about a play is used unless it is knowable before the snap.

Pass includes dropbacks that end in a sack or scramble. Kneel-downs, spikes and two-point tries are left out. The public benchmark is nflfastR's expected pass model, the standard open-source reference.

The live in-season model runs on data available during the season; the historical model uses additional pre-snap data that is published after each season.
